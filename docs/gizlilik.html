Gizlilik Politikası

Son güncelleme: 22 Kasım 2026

Tuzak Soru Yayın aracı yalnızca kanal sahibinin kendi YouTube ve TikTok hesaplarına kendi videolarını yüklemek ve zamanlamak için kullanılır.

Toplanan veriler: Araç, yalnızca video yüklemek için gereken erişim anahtarlarını kullanır. Başka kullanıcıların verisi toplanmaz, saklanmaz, satılmaz veya üçüncü kişilerle paylaşılmaz.

Google ve TikTok verileri: YouTube Data API ve TikTok Content Posting API üzerinden alınan izinler yalnızca video yüklemek için kullanılır. Araç, Google API Services User Data Policy kurallarına, Limited Use şartları dahil, uyar.

İzni geri alma: Kanal sahibi verdiği izni dilediği zaman Google hesabı ayarlarından veya TikTok uygulama ayarlarından geri alabilir.
